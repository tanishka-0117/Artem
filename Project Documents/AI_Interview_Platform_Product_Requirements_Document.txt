1. Product Vision
The platform is a unified interview-preparation and placement-readiness application. It combines authentication,
candidate dashboards, AI-powered interviews, resume analysis, a structured question bank, coding practice, and
progress tracking into one product experience.
The product should help a candidate prepare, assess performance, understand weak areas, and continuously
improve through targeted practice and feedback.

4. AI Interview
Users can configure the interview before starting it.
Configuration
Available Options
Interview Type
Technical, HR, Behavioral, System Design, Resume Based, Company
Specific
Difficulty
Beginner, Intermediate, Advanced
AI interview behavior:
1. Ask a question.
2. Wait for the candidate's answer.
3. Analyze the answer.
4. Give a score.
5. Explain strengths.
6. Explain weaknesses.
7. Suggest improvements.
8. Ask the next question.
The sequence is intentionally interactive: question → answer → analysis → feedback → next question.

5. Resume Analyzer
The user uploads a resume. The system analyzes the resume using AI and returns structured preparation
insights.
Resume Analysis Area
What is analyzed
Skills
Technical and role-relevant skills present in the resume.
Experience
Work/internship/project experience and relevance.
Projects
Project descriptions, technologies and demonstrated work.
Education
Educational background and related information.
ATS Compatibility
Resume structure and keyword alignment for ATS-oriented review.
Missing Skills
Skills that appear important but are missing or underrepresented.
Weak Descriptions
Project/experience descriptions that can be made stronger.
Grammar
Language and writing issues.
Impact Statements
Whether achievements communicate measurable impact.
The AI should generate:
• Resume score
• Improvement suggestions
• Interview questions based on the resume
• Skill-gap analysis
The resume module therefore acts as both a resume-review feature and an input source for personalized
interview preparation.
6. Mock Interview
Before starting a mock interview, the user selects:
• Job role
• Experience level
• Interview type
• Difficulty
• Duration
The system then generates and conducts a realistic interview based on those settings.

10. Product-Level Interaction Flow
Register/Login → Dashboard → Upload Resume → AI Resume Analysis → Select Interview/Practice → Complete
Assessment → Receive Feedback → Track Progress → Follow Recommendations → Re-assess
11. Product Acceptance Outcome
A successful implementation should allow a user to create an account, maintain a profile, analyze a resume, start
a configured mock interview, practice coding, use the question bank, receive AI feedback, and review progress
analytics from a single web application.
The product requirements in this document define the requested user-facing functionality. Detailed architecture,
database design, API contracts, AI implementation rules, security controls and testing procedures should be
maintained in their respective project documents.
