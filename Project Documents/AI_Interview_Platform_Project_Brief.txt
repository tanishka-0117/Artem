1. Problem Statement
Students already have many tools for coding practice, interview preparation and resume improvement, but
these activities are often disconnected. A student may practice hundreds of DSA problems and still not know
whether they are ready for a particular role because technical interview performance, project
understanding, communication and resume-job alignment are not considered together.
The core problem is therefore not a lack of content; it is the lack of a unified, personalized and
evidence-based readiness system that answers: “For my target job, what am I good at, where am I
weak, and what should I do next?”

3. Main Objective
The main objective is to build a single platform that continuously converts candidate data and assessment
evidence into actionable preparation guidance. The system should connect resume -> target role -> skill
analysis -> coding/technical assessment -> adaptive AI interview -> evaluation -> readiness score ->
personalized roadmap -> re-assessment.
The objective is not to replace LeetCode, GFG or generic AI tools. The platform is designed to add an
integration, personalization and readiness layer around these preparation activities.

5. What Makes the App Different?
1. Resume-aware interviews: Questions are based on what the candidate actually claims in the resume, not
only a generic question bank.
2. Adaptive questioning: The next question depends on the previous answer, so the interview can test depth
rather than only memorized responses.
3. Evidence-based skill model: Coding, interview, project-defense and resume evidence contribute to a
candidate skill profile.
4. Job-specific readiness: Instead of a generic score, the system estimates readiness against a selected
target role.
5. Action after assessment: The product does not stop at feedback; it generates a prioritized roadmap and
uses later attempts to update it.
6. AI is not the whole system: Objective tasks remain deterministic. For example, code correctness
comes from actual execution against test cases; AI is used for language-based evaluation, generation

9. Final Project Definition
AI Interview Preparation & Assessment Platform is a MERN-based AI-enabled placement-readiness
system that connects resume analysis, target-job matching, coding and technical assessment,
adaptive interview simulation, project defense, structured evaluation, performance analytics and
personalized preparation into one continuous learning and assessment workflow.
